# 이터널 리턴 알리미 (디스코드)

30분마다 이터널 리턴 소식을 확인해서 **스킨 · 새 시즌 · 쿠폰 · 점검 · 패치노트** 소식만 디스코드 채널로 보내 줘요.
서버 없이 GitHub Actions로 돌아가고(무료), 설치할 패키지도 없어요.

## 무엇이 오나요

**Steam 한국어 공지** (store.steampowered.com/news/app/1049590 에 올라오는 것)

| 공지 | 알림 |
|---|---|
| 쿠폰 코드가 들어 있는 공지 | ✅ 항상 (코드를 따로 크게 보여 줌) |
| 서버 점검 안내 / 점검 완료 / 임시·긴급 점검, 패치노트, 핫픽스 | ✅ 항상 |
| 제목에 `스킨`이 있는 공지 | ✅ (단, `당첨자`·`오류`·`이상 현상`이 들어간 건 제외) |
| 새 시즌 소식 | ✅ 새 시즌 번호(예: 시즌 14)가 처음 나온 날부터 **3주 동안** 그 시즌 공지 |
| 이모티콘, 만화, 지난 시즌 공지, '점검 이후 확률 변경' 같은 점검 관련 기타 안내 등 | ⏭ 안 옴 |

공지에 유튜브 영상이 붙어 있으면 링크를 같이 보내서 디스코드 안에서 바로 재생돼요.

**유튜브 이터널 리턴 한국 채널** (@EternalReturnKR, 쇼츠 포함)

- 제목이나 설명에 `스킨`, `시즌`, `미리보기`, `찾아옵니다` 가 있는 영상만 와요.
  스킨 쇼츠는 보통 `#신규스킨` 태그가 붙거나 설명에 "○○가 루미아 섬에 찾아옵니다!"라고 적혀 있어서 이걸로 잡아요.
- 제목에 `KEL`, `마스터즈`, `서포트 패키지`, `비하인드` 가 있는 대회·홍보 영상은 빼요.
- `미리보기`는 신규 캐릭터 미리보기도 같이 잡아요. 싫으면 아래 설정에서 키워드를 바꾸면 돼요.

같은 쿠폰이나 같은 영상이 여러 곳에 나와도 한 번만 보내요.

## 설치 (10분)

### 1. 디스코드 웹후크 만들기
알림 받을 채널의 톱니바퀴(채널 편집) → **연동** → **웹후크** → **새 웹후크** → **웹후크 URL 복사**

> 이 URL만 있으면 누구나 그 채널에 글을 쓸 수 있으니 코드에 직접 넣지 말고 아래처럼 Secret에 넣어요.

### 2. GitHub 저장소 만들기
1. 새 저장소 만들기 (**Public 추천**: 비공개 저장소는 Actions 무료 사용 시간에 한도가 있어요. 웹후크 URL은 Secret이라 공개돼도 안전해요.)
2. `bot.py`를 저장소 최상단에 업로드
3. **Add file → Create new file** 에서 파일 이름 칸에 `.github/workflows/er-news.yml` 을 그대로 입력하고, `er-news.yml` 내용을 붙여넣어 커밋
   (점으로 시작하는 폴더는 드래그 업로드할 때 빠지는 경우가 많아서 이 방법이 확실해요.)

### 3. 웹후크 URL 등록
저장소 **Settings → Secrets and variables → Actions → Secrets** 탭 → New repository secret
- Name: `DISCORD_WEBHOOK_URL`
- Secret: 복사한 웹후크 URL

여기까지 하면 기본 설정(위 표대로)으로 동작해요. 바꾸고 싶은 게 있을 때만 아래 4번을 해요.

### 4. (선택) 설정 바꾸기
같은 화면의 **Variables** 탭 → New repository variable. 안 넣은 항목은 기본값을 써요.

| Name | 기본값 | 설명 |
|---|---|---|
| `MENTION` | (없음) | 쿠폰 알림 때 붙일 멘션. `@everyone` 또는 `<@&역할ID>` |
| `STEAM_KEYWORDS` | `스킨` | 제목에 이 단어가 있는 Steam 공지를 보냄. 쉼표로 여러 개. 예: `스킨,신규 캐릭터` |
| `STEAM_PATCH_KEYWORDS` | `패치노트,핫픽스,서버 점검,점검 안내,점검 완료,임시 점검,긴급 점검` | 제목에 이 단어가 있으면 제외 단어와 상관없이 보냄. 점검·패치노트를 끄려면 `none` |
| `STEAM_EXCLUDE` | `당첨자,오류,이상 현상` | 제목에 이 단어가 있으면 안 보냄 (쿠폰·점검·패치노트 공지는 예외) |
| `SEASON_WINDOW_DAYS` | `21` | 새 시즌 소식을 받을 기간(일). `0`이면 새 시즌 소식 끔 |
| `YOUTUBE_CHANNELS` | 이터널 리턴 한국 채널 | 채널 주소를 쉼표로 여러 개. `off`면 유튜브 알림 끔 |
| `YOUTUBE_KEYWORDS` | `스킨,시즌,미리보기,미리 보기,찾아옵니다` | 제목/설명에 이 단어가 있는 영상을 보냄 |
| `YOUTUBE_EXCLUDE` | `KEL,마스터즈,서포트 패키지,비하인드` | 제목에 이 단어가 있으면 안 보냄 |
| `YOUTUBE_SHORTS` | `on` | `off`면 쇼츠 제외 |

키워드 칸에 `*`를 넣으면 전부 보내고, `none`을 넣으면 키워드로는 아무것도 안 보내요. 예를 들어 `STEAM_KEYWORDS`를 `none`으로 두면 Steam에서 스킨 공지는 빠지고 쿠폰·점검·패치노트·새 시즌 소식만 와요.

### 5. 실행 확인
**Actions** 탭 → 왼쪽 `이터널 리턴 알림` → **Run workflow** → `mode` 선택

1. **check** → 채널에는 아무것도 안 보내고, 지금 올라와 있는 공지·영상이 각각 ✅ 보냄 / ⏭ 건너뜀 중 무엇인지 실행 로그에 이유와 함께 찍어 줘요. 필터가 마음에 드는지 여기서 확인하세요.
2. **test** → 필터를 통과하는 최신 공지 1개와 영상 1개를 채널로 보내요. 오면 웹후크 연결 성공.
3. **normal** → 첫 실행은 지금 있는 공지·영상을 **기록만** 하고 알림은 안 보내요 (채널 도배 방지). `state.json`이 생기면 준비 끝.

이후로는 30분마다 알아서 돌아요. 실행 로그에서 무엇을 보내고 무엇을 왜 건너뛰었는지 볼 수 있어요.

## 내 PC에서 돌려 보기

```bash
# macOS / Linux
export DISCORD_WEBHOOK_URL="웹후크 URL"
python bot.py --check       # 보냄/건너뜀 목록만 (웹후크 없어도 됨)
python bot.py --test        # 필터 통과하는 최신 공지·영상 1개씩 전송
python bot.py               # 평소 실행
```

```powershell
# Windows PowerShell
$env:DISCORD_WEBHOOK_URL="웹후크 URL"
python bot.py --check
```

## 알아 둘 점

- Steam 한국어 공지는 **Steam 상점 뉴스 페이지가 내부적으로 쓰는 주소**에서 가져와요. 공식 API가 아니라서 Steam이 페이지 구조를 바꾸면 깨질 수 있어요. 그러면 Actions가 실패로 표시되고 GitHub에서 메일이 와요.
- 유튜브 RSS는 가끔 잠깐씩 응답이 안 될 때가 있어요. 그럴 땐 경고만 남기고 다음 실행 때 다시 확인해요 (Steam 알림에는 영향 없음).
- 쿠폰 코드가 이미지에만 있거나 방송에서만 공개되면 코드를 못 뽑아요.
- 필터에 걸려 건너뛴 공지·영상은 나중에 키워드를 바꿔도 다시 오지 않아요.
- 공개 저장소는 **60일 동안 활동이 없으면 예약 실행이 꺼져요.** 새 공지가 올 때마다 `state.json` 커밋이 생겨서 보통은 괜찮지만, 꺼지면 Actions 탭에서 다시 켜 주면 돼요.
- GitHub 예약 실행은 몇 분씩 늦게 돌 때가 있어요.
